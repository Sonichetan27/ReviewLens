# ReviewLens

Mobile-first AI-powered review intelligence and personalized recommendation platform.

Scaffold only — client (React/Vite/Tailwind) and server (Node/Express/MongoDB) are empty-but-valid starters. Business logic is not implemented yet.

## Structure

- `client/` — frontend
- `server/` — backend
- `data/` — seed JSON placeholders
- `docs/` — architecture docs (placeholders)

## Setup

```bash
cd client && npm install && npm run dev
cd server && npm install && node server.js
```

Copy `.env.example` to `.env` (and `client/.env` for `VITE_API_URL` when needed).
